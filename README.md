# Mooketsi Katlego Portfolio

A modern, futuristic portfolio website built with React, TypeScript, and styled-components.

## Tech Stack

- **Frontend:** React 18, TypeScript
- **Styling:** Styled Components, CSS-in-JS
- **Animations:** Framer Motion
- **Routing:** React Router v6
- **Forms:** Formspree
- **Icons:** React Icons (Feather Icons)
- **Deployment:** GitHub Pages

## Features

- ✨ Futuristic design with neon/cyberpunk aesthetic
- 🎨 Glassmorphism UI components
- 🌟 Animated particle background
- 📱 Fully responsive design
- ♿ Accessible (WCAG compliant)
- ⚡ Optimized performance (125KB gzipped)
- 🔍 SEO optimized with Schema.org
- 📧 Functional contact form (Formspree)

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

Opens the app at http://localhost:3000

### Build

```bash
npm run build
```

Creates an optimized production build in the `build/` directory.

### Deployment

This project uses GitHub Pages for deployment. The workflow is:

1. **Main branch** contains the source code
2. **gh-pages branch** contains the deployed build artifacts

To deploy:

```bash
npm run deploy
```

This builds the project and pushes the `build/` directory to the `gh-pages` branch.

## Workflow

### Making Changes

1. Make your changes on the `main` branch
2. Test locally with `npm start`
3. Commit and push to `main`:
   ```bash
   git add .
   git commit -m "Your message"
   git push origin main
   ```
4. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```

### Branch Structure

- `main` - Source code (this is where you work)
- `gh-pages` - Deployed build artifacts (auto-generated by `npm run deploy`)

**Never work directly on gh-pages** - it's managed by the deployment script.

## Customization

### Update Contact Information

Edit `src/components/Contact/Contact.tsx`:
- Formspree ID: Line 170
- Email: Line 238
- Location: Line 242

### Update Social Links

Edit the following files:
- `src/components/Home/Home.tsx` - Hero section social links
- `src/components/Footer/Footer.tsx` - Footer social links
- `src/components/Header/Header.tsx` - LinkedIn link

### Add/Remove Projects

Edit `src/components/Projects/Projects.tsx`:
- Add/remove projects from the `projects` array
- Update project details, tech stack, and links

### Update Skills

Edit `src/components/Skills/Skills.tsx`:
- Modify the `skills` object to add/remove skills
- Adjust skill levels and categories

### Customize Theme

Edit `src/styles/theme.ts`:
- Colors: Modify the `colors` object
- Typography: Adjust fonts and sizes
- Spacing: Change spacing scale
- Animations: Modify transitions and effects
